# Data Professional Survey Breakdown | Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to explore survey responses from data professionals. It provides insights into respondents' demographics, job roles, average salaries, favourite programming languages, and workplace satisfaction.

The dashboard transforms survey data into interactive visualizations that make it easier to understand trends and compare responses across different categories.

## Objectives

The main objectives of this project are to:

- Analyze the demographics of survey respondents.
- Explore average salaries across different data-related job titles.
- Compare survey responses regarding work-life balance and salary satisfaction.
- Examine respondents' favourite programming languages.
- Visualize responses to questions about the difficulty of entering the data profession.
- Present key metrics in an interactive dashboard for easier exploration.

## Tools and Technologies

- **Microsoft Power BI Desktop** — dashboard development and data visualization.
- **Power Query** — data preparation and transformation, where applicable.
- **DAX** — measures and calculations, where applicable.
- **Data visualization** — KPI cards, gauge charts, donut charts, and bar charts.

## Key Dashboard Features

### 1. KPI Cards
Display the total number of survey takers and the average age of respondents.

### 2. Workplace Satisfaction
Gauge charts present respondents' reported happiness with work-life balance and salary.

### 3. Salary Analysis
A horizontal bar chart compares average salaries across data-related job titles.

### 4. Programming Language Preferences
A stacked column chart explores respondents' favourite programming languages and their distribution across job categories.

### 5. Survey Response Analysis
A donut chart visualizes responses to a question about the difficulty of entering the data profession.

### 6. Interactive Country Filter
Users can filter the dashboard by country to explore the available survey responses for selected locations.

## Initial Observations

Based on the displayed dashboard:

- The report shows 630 survey takers.
- The average age of respondents is approximately 29.87 years.
- The displayed work-life balance happiness score is 5.74.
- The displayed salary happiness score is 4.27.
- Data Scientist and Data Engineer roles have relatively high average salary values in the displayed comparison.
- Python is the most frequently represented programming language in the displayed chart.

These observations describe the current dashboard view and should not be interpreted as conclusions about all data professionals.
